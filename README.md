# 💫 Muhammad Ijaz Abbas — Portfolio

A personal portfolio site built with plain HTML, CSS and JavaScript.

## Sections

- **About** — who I am and what I focus on
- **Projects** — showcase of recent work
- **Skills** — languages and tools I use
- **Contact** — GitHub and LinkedIn links

## Features

- Smooth scroll navigation
- Scroll-reveal animations on section entry
- Sticky navbar with scroll shadow
- Fully responsive layout (mobile to desktop)

## Tech stack

- HTML5
- CSS3 (Grid, Flexbox, custom properties, animations)
- Vanilla JavaScript (Intersection Observer for scroll-reveal)

## How to run

1. Clone or download this repository.
2. Open `index.html` directly in any browser — no build step or server required.
3. Optional: use the **Live Server** VS Code extension for auto-reload while editing.

## Deploy

This site is a static build — deploy for free on GitHub Pages, Netlify, or Vercel with no configuration.

## File structure

```
├── index.html   # Page structure and sections
├── style.css    # Theme, layout and animations
└── script.js    # Scroll-reveal and navbar behavior
```
